# Wishlist app

This will be a web app that enables users to make and edit their own wishlists and share them with other users.<br/>
Other users can *reserve* items on the lists. The owner of the list however, doesn't see which items are reserved.

This app should help people to share what they wish for eg. birthdays without ruining the joy of a surprise - the owners don't know which items will be given to them and by whom.


Describe a function of developed application, necessary dependencies (e.g. utilize requirements.txt), how to start it, and last but not least how to run tests from CLI.
